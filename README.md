# bostadsfilm.cbmedia.se

Visningssida för CB Medias boostade bostadsfilmer. Statisk sida, publicerad med GitHub Pages.

- `index.html` – sidan (all text statisk för Google och AI-crawlers)
- `sitemap.xml` – videokarta för Google
- `robots.txt` / `llms.txt` – för sökmotorer och AI-assistenter
- `ig-*.webp` – Instagram-filmer med visningssiffror
